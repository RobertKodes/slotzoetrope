# slotzoetrope

Live Solana mainnet as a **Victorian zoetrope**.

The drum spins with the slot clock. Figures glimpsed through the slits are recent txs — costume color by program family. Spin blur / lamp heat ≈ fee pressure. Torn paper figures and jammed slits ≈ failed txs. Hold the crank (or close the shutter) to freeze a frame strip.

Not an explorer. Not a dashboard. Not a newspaper.
